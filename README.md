# Dra. Carla Campos

Base moderna e responsiva para website institucional em `Next.js`, com paleta roxa, animacoes leves usando `framer-motion` e estrutura pronta para evoluir.

## Rodar localmente

```bash
npm install
npm run dev
```

Depois, abra `http://localhost:3000`.

## Estrutura principal

- `src/components/home-page.tsx`: home institucional com animacoes e seccoes prontas.
- `src/components/home-page.module.css`: identidade visual, responsividade e refinamento visual.
- `public/assets/logos`: pasta para logo oficial.
- `public/assets/photos`: pasta para fotos da medica, clinica e equipe.

## Substituicoes rapidas

- Troque `public/assets/logos/logo-placeholder.svg` pela logo final.
- Troque `public/assets/photos/doctor-placeholder.svg` pela foto principal.
- Troque `public/assets/photos/clinic-placeholder.svg` pela foto da clinica ou consultorio.
- Ajuste textos, contatos e CTAs em `src/components/home-page.tsx`.
